# Smart Journey Kids — Website

A responsive multi-page static website built for Smart Journey Kids.

## Pages
- Home
- Activities
- Painting Studio
- Games
- Stories
- Worksheets
- Shop
- Contact

## Brand asset
The supplied Smart Journey Kids logo is used at:
`assets/smart-journey-kids-logo.png`

## WhatsApp
Before publishing, replace `94770000000` in `assets/app.js` and the WhatsApp links with the real business number.

## Run
Open `index.html` in a browser. For deployment, upload the folder to Netlify, Vercel, or GitHub Pages.

## Notes
The site uses Google Fonts and Unsplash photography through remote URLs, so an internet connection is needed for those external assets.
